Stage 1 of macOS support (#32): Popamp builds, lints and passes its tests on macOS, with a macOS CI job after merges to `main`. Nothing changes on Linux or Windows.

**The cfg split.** `cfg(unix)` meant Linux, so macOS got X11, ALSA and D-Bus and the build failed. A build-script cfg, `linux_like` (every Unix but macOS, declared with `cargo::rustc-check-cfg`), now marks the code that needs X11, ALSA, D-Bus, fontconfig, zenity, XDG or `mimeapps.list`. That includes 0.9's tray (StatusNotifierItem), notifications, and the X11/portal hotkeys. Plain `unix` stays only where the code is POSIX:
- the control socket (`ipc.rs`);
- the `sh` pipe sources and their tests (`popamp-audio` `pipe.rs`, `engine.rs`);
- file semantics in `tags.rs` and paths in `plformats.rs`;
- symlinks and `sh` in `popamp-plugins`.

`Cargo.toml`'s target table can't see build-script cfgs, so the X11/D-Bus dependencies there are under `cfg(all(unix, not(target_os = "macos")))`.

**macOS modules,** one next to each existing system's, behind the same interface. In this stage they do nothing yet, or the least that works:
- sound output that opens only `null`, so a track fails with "Popamp cannot play sound on macOS yet" rather than racing through the playlist;
- plain winit windows;
- dialogs, a tray, media controls and global hotkeys that are not there yet (each logs once);
- a system font every Mac has.

Later stages fill them in, one PR each: CoreAudio, then daily use (Retina, dialogs, CoreText, Finder), then the Mac keys and shapes, then packaging.

**Libraries:** libopus and libopenmpt load on macOS from the app bundle's `Frameworks`, then Homebrew's `/opt/homebrew/lib` and `/usr/local/lib`, by whole path only (a bare name would make the loader look in the current folder). The bundle path is used only for a program inside `.app/Contents/MacOS`.

**One shared-code change:** `ipc::answer` took `for<'a> &'a S: Read + Write`, which sends the trait solver round objc2's blanket impls forever on macOS. It now takes the shared reference itself (`S: Read + Write + Copy`), which reads the same for `&UnixStream` and `&File`.

**CI:** a `macos` job on `macos-15`, GitHub's hosted runner, with clippy and tests for the three feature sets, running after merges to `main` only (`if: github.event_name == 'push'`).

**Tested:**
- `cargo fmt`, clippy (`-D warnings`) and tests for default, `popamp/plugins` and `popamp/plus` on an Apple Silicon Mac (409 / 420 / 421 tests).
- Linux, Windows and MSRV CI in my fork: https://github.com/miraclebg/popamp/pull/7
- The player starts on macOS with the default skin, and a second `popamp` command reaches the running one through the control socket.
