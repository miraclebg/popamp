# Задание на следующую сессию: проверка PR #29 на Linux

Написано 2026-11-10 после работы на Windows 11. Работа идёт на Linux (X11).
Удалить этот файл перед слиянием PR #29 в `main`.

## Контекст

- Ветка `fix-windows-popups-minimize-dialogs`, PR https://github.com/popamp/popamp/pull/29.
  Описание PR перечисляет все изменения.
- Всё проверено только на Windows 11: fmt, clippy (с `popamp/plus` и без),
  `cargo test --workspace`, ручные проверки и рендеры. **На Linux не проверялось ничего.**
- Тема Modern (`popamp/skin-modern`, `main`, коммиты `1c687d9` и `e47505b`)
  уже использует `align = "right"` у часов и `min_popamp = "0.8.0"`. Тега нет.
  Popamp 0.7 эту тему не загрузит, это ожидаемо.

## Шаги

1. `git fetch && git checkout fix-windows-popups-minimize-dialogs && git pull`
2. Прогнать проверки из CONTRIBUTING.md:
   `cargo fmt --all --check`,
   `cargo clippy --workspace --all-targets -- -D warnings` (и с `--features popamp/plus`),
   `cargo test --workspace`.
   Golden-тесты могут разойтись на пиксель из-за центрирования часов
   по цифрам (`render::clock` → `Canvas::text_centred`). Если расхождение
   только в часах векторных скинов, посмотреть картинки и перезаписать
   эталоны: `POPAMP_BLESS=1 cargo test -p popamp golden`.
3. Проверить руками вместе с пользователем:
   - **Меню, подсказки и свои диалоги**: размер берётся из системного
     масштаба (`Xft.dpi`), а не из размера окон плеера (`App::dialog_pct`).
     Включить Double Size: меню и диалоги не должны вырасти. Если есть
     возможность, проверить при `Xft.dpi` больше 96.
   - **Сворачивание**: `App::set_minimized`. На X11 `OWNED_FOLLOW_OWNER = false`,
     поэтому сворачиваются все видимые окна, как раньше. Эквалайзер и плейлист
     должны вернуться вместе с главным окном.
   - **Контекстное меню**: открывается и не закрывается сразу.
     `Platform::no_activate` на X11 пустой, окна override-redirect.
   - **Бар-режим** (тема Bar, сверху и снизу): после резервирования полосы
     бар не уползает, место освобождается после выхода. Изменены
     `App::update_bar_area` и обработчик `WindowEvent::Moved`.
   - **Steel на ×1.5**: последняя цифра часов не обрезана.
   - **Modern**: часы стоят у вертикальной полоски перед «POPAMP»
     и по высоте посередине поля.
   - **Визуализация** (сборка `--features popamp/plus`): спектр рисуется.
     Изменён `visualizer.rs`: дескрипторы окна берутся в UI-потоке.
4. Если всё в порядке: удалить этот файл отдельным коммитом в ветке, сказать
   пользователю, что PR #29 можно сливать. После выпуска 0.8 поставить тег
   у `popamp/skin-modern` (предложить `v1.1.0`). Без согласия пользователя
   не сливать и тегов не ставить.
5. Если что-то сломано: исправить в этой же ветке, добавить строку в
   CHANGELOG `[Unreleased]`, прогнать проверки, закоммитить и запушить.
